## Установка зависимостей (server)

1. Перейдите в директорию сервера:

```bash
cd server
```

2. Установите пакеты:

```bash
npm install
```

## Запуск сервера

### В режиме разработки:

```bash
npm run dev
```

### Запуск приложения:

**Сборка (если требуется):**

```bash
npm run build
```

**Сам запуск:**

```bash
npm start
```
